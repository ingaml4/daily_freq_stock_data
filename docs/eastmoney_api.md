# 东方财富免费接口速查（本项目用到的两个）

> 这两个接口是东方财富行情页面本身在用的公开接口，不需要 token/key。
> 但它是"未公开文档的内部接口"，字段和参数随时可能调整，所以本项目：
> ① 解析逻辑全部写成纯函数并配了单测；② 提供 `python3 -m emscan check --probe`
> 用来在真实网络下打印原始样本，方便第一时间发现字段变化。

## 1. 全市场行情快照 / 股票列表

```
GET https://push2.eastmoney.com/api/qt/clist/get
```

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `fs` | `m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23` | 板块过滤，逗号分隔 |
| `pn` / `pz` | `1` / `100` | 页码 / 每页条数（分页取全市场） |
| `po` / `fid` | `0` / `f12` | 按代码升序，保证分页稳定不重复 |
| `np` | `1` | `1` 时 `data.diff` 是 `{"0":{...}}` 字典，`0` 时是数组 |
| `fltt` / `invt` | `2` / `2` | 返回真实数值（非整数放大） |
| `ut` | `bd1d9ddb04089700cf9c27f6f7426281` | 页面里写死的公开 token |
| `fields` | 见下表 | 需要哪些列 |

板块 `fs` 取值：

| 本项目名称 | fs | 含义 |
| --- | --- | --- |
| `sh_main` | `m:1+t:2` | 沪市主板 |
| `sh_star` | `m:1+t:23` | 科创板 |
| `sz_main` | `m:0+t:6` | 深市主板 |
| `sz_gem` | `m:0+t:80` | 创业板 |
| `bse` | `m:0+t:81+s:2048` | 北交所 |

常用字段：

| 字段 | 含义 | 单位/备注 |
| --- | --- | --- |
| `f2` | 最新价 | 元（收盘后=当日收盘价） |
| `f3` / `f4` | 涨跌幅 / 涨跌额 | % / 元 |
| `f5` | **成交量** | **手**（1 手 = 100 股） |
| `f6` | **成交额** | 元 |
| `f7` | 振幅 | % |
| `f8` | **换手率** | % |
| `f10` | 量比 | 倍（东财口径，仅快照有） |
| `f12` / `f13` | 代码 / 市场 | 市场 `1`=沪，`0`=深；`secid = f13.f12` |
| `f14` | 名称 | 含 `ST`/`退` 的会被本项目默认剔除 |
| `f15`/`f16`/`f17`/`f18` | 最高/最低/今开/昨收 | 元 |
| `f20` / `f21` | 总市值 / 流通市值 | 元 |
| `f26` | 上市日期 | |
| `f124` | 行情时间戳 | 秒级 Unix 时间，用它判断"今天是不是交易日 / 数据是否已更新" |

## 2. 个股日K线

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
```

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `secid` | `1.600519` | `市场.代码` |
| `klt` | `101` | 101=日线（102=周线，103=月线） |
| `fqt` | `1` | 0=不复权，1=前复权，2=后复权 |
| `beg` / `end` | `0` / `20500101` | 起止日期，`0` 表示最早 |
| `fields1` | `f1,f2,f3,f4,f5,f6` | 元信息 |
| `fields2` | `f51,...,f61` | K线字段（顺序固定） |

`data.klines` 是字符串数组，每行 11 个字段，顺序为：

```
f51 日期, f52 开盘, f53 收盘, f54 最高, f55 最低,
f56 成交量(手), f57 成交额(元), f58 振幅%, f59 涨跌幅%, f60 涨跌额, f61 换手率%
```

同时返回 `data.name / code / market / decimal`（小数位数）。

## 3. 踩坑记录

* **缺失值写成 `-`**：解析时必须转成 `None`，否则 `float()` 会炸。
* **停牌股当日没有 K 线**，快照里成交量/成交额为 0。本项目不把这种行写进 `bars`，
  否则会污染基准计算；扫描时也会按"当日无成交"跳过。
* **前复权价会随除权变化**：历史 K 线用 `fqt=1`，快照里的 `close` 是不复权价。
  量能指标（成交量、成交额、换手率）与复权无关，因此不影响放量判断；但如果以后要
  做"价格形态"类信号，需要统一口径（全部走 kline 接口，或全部用不复权）。
* **限流**：普通查询不会触发，但 5000+ 只股票全量回补时建议 `workers` 控制在 8~16，
  并在请求间加少量随机延时（默认 `sleep: 0.05`）。真被限流就调小并发、加大重试间隔。
* **`lmt` 语义**：为保证"从某个日期起补齐"的确定性，本项目回补/补漏只用
  `beg` + `end` 控制范围，不依赖 `lmt`。
* **板块归属由 secid 反推**（沪 `688`=科创板、深 `300/301`=创业板、`4xx/8xx`=北交所），
  没有额外请求；若东财改版或出现新代码段，改 `emscan/cli.py:board_of()` 一处即可。
