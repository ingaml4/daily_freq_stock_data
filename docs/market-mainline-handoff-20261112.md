# 市场主线与锚点 · 开发交接（2026-11-12）

功能位于「收盘复盘」的市场主线区块，日期选择同时控制主线和复盘正文。当前为开发验收版本，生产仍运行原版，11 月 12 日 17:16 可由主会话沿用原有收盘数据。

## 只读接口

`GET /api/market-mainline?date=YYYY-MM-DD` 沿用网站 Cookie 或 Basic 认证。省略 date 时读取库内最新有记录的交易日；显式日期只查该日。日期格式、重复参数或未知参数错误返回 400；无认证返回 401。可解释的行情、映射和历史缺口返回 200 并给状态。网页按日期请求，后台只读取本地 SQLite，无供应商调用。

| 字段 | 契约 |
| --- | --- |
| `schema_version`、`date`、`dates` | 版本 1.0、请求交易日、近期最多 250 个历史交易日 |
| `status`、`publication_ready`、`gaps` | waiting 等待该日数据，degraded 存在缺口，ready 数据与映射具备。仅概念缺失时仍可 publication_ready=true；行情未齐时为 false |
| `market`、`coverage` | readiness 市场阶段原字段及 after_close_snapshot，有成交、无成交、未确认、可用涨跌额样本、行业覆盖、锚点权限排除数、用于比较的日期和日历来源 |
| `mappings` | 按 sw、gn、chgn 给出供应商成分接口、采集版本时间、节点和证券数 |
| `benchmark` | 同日库内有成交且价量有效证券的涨跌幅中位数、样本数。覆盖按本站沪深行情库解释，包含有行情的科创板作市场统计 |
| `mainlines` | 0–3 条。每条有 kind/key/name、evidence、重叠组和 anchors。evidence 记录成分、有效样本代码、上涨数及比例、中位涨幅和相对市场百分点、成交额与前五日同一组样本中位数、成交集中度、领涨与跟涨、近五日逐日证据 |
| `anchors` | 每条最多 3 个不同证券。记录角色、代码、证券主表名称、涨跌、成交额、近五日相对成交额、收盘/最低、行情来源以及确认、失效数值。允许空 |
| `observations` | 最多 3 个尚未确认的相对偏强分组，附失败原因；弱广度归为个股层面，广度足够但证据未齐归为偏强待核 |
| `previous` | 上一交易日、是否可评估、此前主线在请求日的 continuing / diverging / fading / pending 及当前广度与相对强度 |
| `publication` | computed 为查询时计算，archived 为已保存的同一行情覆盖版本与生成时间 |

接口与盘后归档实现分别见 `emscan/web.py` 和 `emscan/market_mainline.py`。前端为 `frontend/src/components/MarketMainline.vue`，由 `SummaryView.vue` 渲染。

## 就绪与判定

- 使用现有 readiness 市场阶段。覆盖记录须为请求日收盘后、已核实股票池，未确认数必须为 0；同日有效涨跌和成交额须覆盖至少 98% 有成交行。近五日要求各日样本至少达到当日 80%。读取本库已缓存的交易日历补足应有交易日，整日缺失时标记缺口。无缓存时披露依据库内已记录交易日。原有日线表没有逐股交易所源时点，收盘核验依赖盘后覆盖记录。
- 初版规则为可复核阈值。每组至少 10 只有效成分，覆盖至少 80%，上涨占比至少 60%，中位涨幅至少 0.8%，相对市场至少 +0.5 个百分点。去掉涨幅前三后，余下上涨占比也至少 60%。日线同向支持广度判断，盘中同步仍需盘中来源。
- 同组当日和过去五天都存在有效数据的证券组成可比样本，至少覆盖当日有效成分的 80%。当日该样本总成交额须达过去五日每日总成交额中位数的 1.10 倍。用请求日成分回看各交易日，最近三日至少两日达到广度和相对强度条件，或最近五日至少三日达到。阈值用于初版证据筛选，尚无跨市场阶段的策略效果验证。
- 通过的分组按相对涨幅、成交额倍数和上涨占比排序。两个分组至少共享八只且交并比达 50%，或共享成分达小组的 80%，保留先排的一组并记关联组。只有申万一级的日期以行业口径展示。行业归属按首次可知时间使用，沪深市场统计与个人锚点范围分别显示。
- 锚点要求证券主表身份、非风险股、有效收盘和最低价、上涨且成交额至少 1 亿元。剔除 SH688/689 及未确认权限的市场。先选合格涨幅领涨，再选其他上涨证券中的成交额核心，最后从仍可比且相对成交达标者选接力验证。用请求日收盘、日内最低和组内证据生成次日确认与失效条件。历史名称和风险状态取目前可用证券主表，缺少逐日证券主表版本。
- 上一日已确认分组若当前继续满足同组条件则延续。上涨占比低于 45% 且跑输市场则退潮；其余有证据但减弱的情形为分化。行情缺口、成分变动使交并比低于 80% 或样本覆盖不足时待核。

市场主线使用独立的市场就绪条件，AI 复盘和两梯队依旧走既有发布路径。库版本 15 新增 `symbol_tag_history`，在原成分整类替换事务内保存旧版本，现有已入库成分也可按时间查询。早于最早可用成分版本的日子返回缺口。原盘后 run 写完 run_finished 后在同一日更进程保存可发布的 `market_mainline_reports`，归档失败记录日志，保持日更原退出结果。历史 GET 仅读取同一覆盖版本的已归档报告或计算视图。

## 验收样本

使用 Personal-Website 生产库只读备份，在隔离副本迁移 v14→v15。所有样本为北京时间。

| 日期或场景 | 实际结果 |
| --- | --- |
| 11-09 真实覆盖完整 | 5,218 只成交，9 只无成交、0 只未确认，申万匹配 5,188/5,218，市场中位涨幅 −0.3497%。可发布的行业口径报告，零条确认主线；隔离副本归档及再次读取通过 |
| 11-10、11-11 真实部分覆盖 | 均缺 4 只；返回具体覆盖与缺口，主线为空且 publication_ready=false。11-11 有效涨跌额 5,218，申万覆盖 5,187 |
| 11-12 盘中副本 | 同日行情尚未落库，waiting，主线为空 |
| 11-06 历史查询 | 同日读取、行业口径、允许零主线。更早无成分版本时返回缺口 |
| 正常行情合成样本 | 12 个上涨成分、9 个跟涨、三种不同锚点，排除 SH688，重合的行业与概念只出现一条 |
