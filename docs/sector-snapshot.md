# Sector snapshot collector contract

Run `python -m emscan.sector_snapshot --membership members.json --output snapshot.json` once per scheduler invocation. This is a read-only quote collector; it does not send messages or place orders. Schedule one shared collector externally. Concurrent attempts for the same resolved output fail on an SQLite `BEGIN IMMEDIATE` lock in the persistent `.run-lock` database. SQLite releases the transaction lock when the process or connection exits, including an unclean process death; the database file may remain and must not be deleted while collectors run. Output is replaced atomically. Each batch contains at most 100 unique symbols, including members shared between sectors.

Input example: `{"sectors":{"燃气":{"source":"Eastmoney BK1028", "observed_at":"2026-11-11", "verified":false, "expected_count":31, "members":[{"symbol":"BJ920010","name":"..."}]}}}`. Symbols must include SH/SZ/BJ and six digits. `verified` means the membership has been independently verified for the intended date, not merely that a file exists. `expected_count` reports unidentified gaps and must reflect the same source/version. A legacy sector list and a direct list of members are accepted as unverified. ST, B shares, BJ and missing quotes remain visible; trading permission is unknown. SH688 has `action_eligible=false` while remaining in coverage.

`build_sector_snapshot_payload(path)` only reads the artifact. It recalculates each row's freshness from the Tencent source timestamp at read time, not from HTTP success or collection time. `received_at`, raw Tencent fields, errors and all configured members remain in the artifact. A missing source timestamp or quote is not fresh. Direct diagnostic runs have `calendar_verified=false`. The deployed `--market-hours --calendar-db data/market.sqlite` checks the cached exchange year calendar and continuous session before requesting quotes, setting `calendar_verified=true` only after that check. Lunch and close are explicit; no minute-bar completeness is asserted. A collector failure still publishes a coverage ledger and returns a nonzero exit status for batch errors; an unavailable artifact must be surfaced by the serving application.

SH688 remains only as an excluded inventory row and is removed before network requests. Coverage separates `listed`, `monitored`, and `excluded_no_permission`. B-share prices carry `price_currency` (USD for SH900, HKD for SZ200); their unverified vendor amount is retained as `amount_reported`, while `amount_yuan` is null so it cannot be compared against CNY thresholds. Exchange currency references are [SSE 2026 trading rules](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml) and [SZSE 2026 trading rules](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf).

The deployment also has a separate user-named observation group for SH603318, SZ301357 and SZ002021. This is an explicit observation scope, not an industry membership claim. With the two historical sector lists, it contains 137 unique symbols; within-sector listed counts are still 31 and 105.
