# 短期策略比较

本轮以买入后五个交易日为主持有期，规则在观察收益结果前固定。比较页面位于 `/strategy-review`，报告和逐笔依据分别位于 `/api/strategy-review`、`/api/strategy-review/orders`，使用网站原认证。

## 四组规则

所有股票均需至少120根截至信号日的有效日线，排除科创板、当前风险警示及不支持市场。

| 方案 | 入场候选与排序 | 退出 |
| --- | --- | --- |
| 原四信号对照 | 复用现有放量上攻、MACD金叉、KDJ金叉、收破布林下轨并集及原评分逻辑 | 买入后第五个交易日收盘 |
| 确认后的机会 | 趋势突破与止跌确认，按相对触发价的收盘位置排序 | 同上 |
| 相对强弱排序 | 同一机会池，行业5/20日强弱与个股相对同行5/20日强弱四项百分位等权 | 同上 |
| 结构与时间退出 | 同一机会与排序 | 固定失效价收盘跌破，下一交易日开盘尝试卖出；否则第五日收盘 |

趋势突破要求收盘超过此前20根有效日线最高价，成交量达到此前20根均量1.5倍，收盘位于当日振幅上部30%，MA20高于MA60。失效价是此前五根有效日线的最低价。

止跌确认要求此前五根日线内出现收破当时布林下轨，首次同时重新收回下轨并收在前一根有效日线高点之上。失效价在确认日固定为该次破轨事件至确认日的最低价。

行业同组比较剔除目标股本身，至少三个有效同行，且覆盖当前行业有效股票的60%。四项排序依据须齐全，缺失时置后。当前行业构成和股票状态均缺少历史版本，属于探索性代理。规则重建的信号日期只代表截断回放，原AI名单真实发布时间及事后补榜记录另行保留。

## 交易与资金

信号日收盘后形成候选，次日开盘开始尝试入场，最长三个交易日。新规则的开盘价格低于或等于固定失效价时取消。新买持仓最早下一交易日卖出，涨跌停、无有效行情和不可核验的公司行为按原模拟器处理。

四组使用相同费用和滑点设置。逐票每笔预算10万元，同时另建初始80万元、最多八只持仓的共享现金组合，已持有同股和资金不足时跳过。开盘卖出的资金可用于同日开盘后的入场，收盘卖出的资金次日才可用。未闭仓继续占用资金，估值或执行数据缺失时组合结果标为无法验证。回放中的日线开收盘成交仍是模型假设，不能证明真实订单成交。

行业排序和退出规则分别作为递进对照，避免将不同条件混称为某一个指标的独立效果。原AI发布名单的表现单列为参考，日期和选股机制不同，不能与规则重建组视为配对实验。

## 验收和数据限制

先按市场日期顺序留前60%作开发观察，其后隔离五个交易日，余下为固定样本外区间。本轮没有按收益调参。主要统计使用共享资金组合的逐日收益差，按连续五个交易日分块重采样5000次，三组比较使用同时置信区间。单笔统计另列，仅表示完成可核验买卖的条件性样本。

上线要求两侧均有至少60个有完成买卖的样本外信号日、100笔可核验买卖、90%执行覆盖，配对净收益改善置信区间下界为正。组合净收益须改善，最大回撤恶化不超过两个百分点，双倍滑点下仍盈利且优于同压力下的对照。历史股票状态、行业构成和指标价格序列均须可核验。这些门槛是本项目预先选定的工程验收标准。

当前库的前复权历史与未复权快照来源混合，股票池与ST状态只有当前版本，行业完整快照始于2026年11月6日。成交快照只从2026年10月13日开始，无法仅靠现有记录满足严格样本外验收。未通过时保存代码和比较证据，正式选股继续使用原规则。

## 重跑

在项目目录使用同一数据副本执行下列命令。脚本读取本地日线，生成报告和逐笔JSON，不发送行情或AI请求。

```bash
EMSCAN_STORE_PATH=/path/to/snapshot.sqlite python3 -m emscan.strategy_review --out /path/to/review-output
```

报告记录数据截止日、代码版本、验收政策哈希、费用参数与数据来源限制。在线页面只读取已经生成的文件。
